# 一家三口跳棋

这是一个无需安装、无需联网的三人本地网页版跳棋。

当前版本支持开局选择昵称、棋子颜色和先手，并按照棋盘逆时针方向轮换回合。

## 开始游戏

最简单的方法：双击 `index.html`，使用电脑浏览器打开。

如果浏览器限制本地文件，可以在本目录打开终端并运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件

- `index.html`：网页入口
- `style.css`：棋盘与界面样式
- `rules.js`：棋盘、合法落点和胜利规则
- `app.js`：回合、动画、昵称、悔棋和调试功能

游戏数据只保存在当前浏览器页面中，刷新或关闭页面会重新开始。
