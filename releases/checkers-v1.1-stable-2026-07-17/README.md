# 一家三口跳棋 v1.1 稳定存档

存档日期：2026-07-17

这是金币系统开发前的稳定版本，已经过家庭实战验证。

## 已包含

- 三人昵称、颜色和先手选择
- 红 → 紫 → 绿的逆时针回合顺序
- 非当前玩家棋子淡化
- 相邻移动、普通跳跃、隔空跳跃和连续跳跃
- 悔棋、手动结束回合、胜负排名和重新开始
- 调试场景与棋盘、棋子独立 ID

## 运行

双击 `checkers-web/index.html`，或在 `checkers-web` 目录运行：

```bash
python3 -m http.server 8000
```

## 回滚

如后续开发出现问题，先保留问题版本，再用本存档中的 `checkers-web` 文件夹替换工作区根目录的 `checkers-web`。
