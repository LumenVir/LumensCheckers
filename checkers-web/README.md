# 闪光跳棋 | Lumen's Checker

这是一个无需安装、无需联网的二至六方本地网页版跳棋，既可以亲友同玩，也可以邀请一位简单电脑加入。

当前版本支持开局选择昵称、棋子颜色和先手，并按照棋盘逆时针方向轮换回合。

完成一次移动后，既可以点击“结束回合”，也可以直接按回车键结束当前回合；输入昵称或操作其他按钮时不会误触快捷键。

## v1.4 玩家卡片与战绩

- 已创建的昵称会显示为玩家卡片，卡片直接展示长期金币余额
- 再次打开网页时，自动带出上一局的两人或三人阵容及各自棋子颜色

- 悔棋同步恢复路径与积分状态，不会因撤回后重走而净增金币

## v1.3 双人模式

- 第一、第二位玩家必填，第三位玩家可选
- 只填写两位时自动开始双人局：先手在正上方，第二位在正下方
- 双人局每方 10 枚、共 20 枚，回合在两位玩家之间切换
- 填写第三位后恢复三人局：三方各 10 枚并按棋盘逆时针轮换
- 双人局和三人局共用金币、悔棋、连续跳跃和胜利排名规则

## 扩展棋子颜色

- 三位玩家依次对应上方、左下、右下营地，可从 11 种颜色中自由选择
- 基础颜色为红、绿、紫；另有唐老鸭蓝、高飞绿、布鲁托橙、米奇黑、白雪公主深蓝、小美人鱼红发、灰姑娘浅灰蓝和乐佩浅金黄
- 允许同一局选择相近颜色，只禁止三位玩家使用完全相同的颜色
- 外观颜色不会改变营地位置、逆时针顺序、目标奖励或胜利判定
- 11 种颜色使用可直接预览和点击的色卡选择，不再使用下拉菜单
- 棋盘使用约 700px 高的六芒星本体，并同步放大落点与棋子

## v1.2 金币系统

- 新玩家初始拥有 10.0 金币；再次输入同一昵称时读取原有长期余额
- 连续跳跃从第 2 跳开始奖励 0.1，单次行动最多奖励 0.5
- 隔空跳按棋子与被跳棋子之间的空位数奖励，每格 0.1，可与连跳叠加
- 每局目标格按深度奖励 0.2、0.4、0.8、1.6，同一目标格每局只能领取一次
- 每回合第一次悔棋扣除 0.5，同一回合继续悔棋不重复扣除
- 同一回合重复经过的落点不再产生跳跃或目标格积分，回合起点也视为已走过
- 跳跃奖励落地时显示，点击“结束回合”后统一进入本局账本
- 完成整局后，本局金币存入长期余额；重新开始会放弃本局收益
- 随机与胜利测试场景不计金币
- 电脑端金币账本位于棋盘左侧，iPad 横屏时移到棋盘下方；调试入口和调试 ID 收在“更多”菜单中

长期余额保存在当前浏览器中；v1.2 暂不恢复刷新前的棋盘残局。

## 开始游戏

最简单的方法：双击 `index.html`，使用电脑浏览器打开。

如果浏览器限制本地文件，可以在本目录打开终端并运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件

- `index.html`：网页入口
- `style.css`：棋盘与界面样式
- `rules.js`：棋盘、合法落点和胜利规则
- `app.js`：回合、动画、昵称、悔棋和调试功能
- `vendor/canvas-confetti.browser.min.js`：终局烟花动画（canvas-confetti 1.9.4）

长期金币、玩家卡片和上局阵容保存在当前浏览器中；刷新或关闭页面会重新开始当前棋局。
