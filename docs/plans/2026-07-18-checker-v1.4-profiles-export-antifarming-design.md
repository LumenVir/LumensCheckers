# 跳棋 v1.4：玩家卡片、战绩导出与防刷分设计

## 目标

减少重复开局操作，让长期金币真正跟随玩家，并限制连续跳跃中通过往返路径重复得分。

## 玩家卡片与上局阵容

- 当前浏览器中的每个玩家档案以独立 ID 保存，昵称和长期金币显示在玩家卡片上。
- 点击玩家卡片即可填入对应座位；同一玩家不能同时占据两个座位。
- 手动输入未见过的昵称时创建新档案，重名昵称继续使用原档案。
- 每次正式开始对局时保存本局人数、座位玩家 ID 和棋子颜色。
- 下次进入开局页时自动恢复上局阵容；两人局保持第三位留空。
- 棋子颜色属于阵容偏好，不属于玩家身份，换色不影响长期金币。

## 同回合重复落点防刷分

- 每回合维护一份 `turnVisitedKeys`，记录当前行动棋子的起点和所有已落地点。
- 落到新格子时，按既有规则计算连跳和隔空跳奖励。
- 落到本回合已经经过的格子时，移动仍然合法，但该次跳跃奖励为零。
- 如果回合最终停在重复落点，该落点的目标营地奖励也为零。
- 跳跃次数仍按真实动作递增，保证连跳上限语义不变。
- 每一步历史同时保存访问集合和最后落点状态；悔棋会撤销该步路径及该步奖励，重走不会带来净增金币。
- 结束回合或重新开局后清空本回合访问集合；目标格“每局仅领取一次”的全局集合保持独立。

## 战绩导出

- 只有整局全部名次确定后显示“导出战绩”。
- 导出 Markdown 文件，包含开始/结束时间、时长、双人或三人模式、排名、每位玩家本局收益和长期余额。
- 调试胜利场景也允许导出，但明确标记为不计金币。
- 战绩是便于阅读和分享的结果记录，不承担残局恢复功能。
