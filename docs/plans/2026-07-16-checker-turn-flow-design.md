# 跳棋回合流程设计

## 回合状态

- 当前玩家按红色、绿色、紫色循环。
- 普通相邻移动完成后保留当前回合，玩家手动点击“结束回合”后才切换。
- 第一次跳跃完成后进入连续跳跃状态，锁定刚才移动的棋子。
- 连续跳跃状态只显示该棋子的跳跃落点，不显示相邻移动。
- 玩家可以继续跳，也可以点击“结束回合”交给下一位。
- 本回合内每次移动都保留一个快照；点击“悔棋”只撤销最近一次移动。连续跳跃会逐跳撤回，并恢复该棋子的连续跳跃锁定。
- 点击“结束回合”或切换测试场景后清空悔棋记录，不能跨回合撤销。

## 交互约束

- 非当前颜色的棋子不能被选中。
- 连续跳跃期间不能改选同色的其他棋子。
- 动画播放期间不能结束回合或切换测试场景。
- 开始新回合时清除选择、落点提示和连续跳跃锁定。
- “重新开始”保留当前测试场景的初始布局，并清空回合、悔棋、排名和胜负状态。
- 为防止误触，第一次点击只进入确认态；3 秒内再次点击才执行重新开始。

## 界面反馈

- 棋盘上方始终居中显示当前玩家颜色；另外两色以禁用态弱化显示。
- “结束回合”按钮在完成一次相邻移动或跳跃后启用。
- “悔棋”按钮在本回合至少移动一次后启用；动画播放时禁用。
- 非法选棋通过侧栏文字说明原因，不改变当前棋盘状态。
