# 跳棋 v1.1 第一批迭代设计

## 本次范围

- 开局按玩家填写顺序登记昵称，并为每位玩家选择红、紫、绿中的一种棋子颜色。
- 第一位玩家为先手；三种颜色不得重复。
- 从先手颜色开始，回合始终沿棋盘逆时针方向轮换：红 → 紫 → 绿 → 红。
- 当前玩家的棋子保持完整颜色，另外两方棋子降低不透明度；顶部非当前玩家提示同步变淡。
- 阵地和目标营地底色保持可见，避免玩家失去目标方向提示。

## 特殊场景

- 标准开局、随机测试和重新开始保持玩家选择的先手与逆时针顺序。
- “红方差一步”测试场景会临时从红方开始，确保胜利测试仍可直接操作。
- 重新开始保留昵称、颜色分配和当前测试场景。

## 下一阶段

- 积分系统单独规划，不在本次改动中加入，避免影响已经实战验证的胜负规则。
